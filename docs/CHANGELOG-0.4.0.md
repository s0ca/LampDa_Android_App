# Lamp-Da Android 0.4.0

- Experimental multi-lamp control: connect up to four lamps and select individual or same-type group targets.
- UART controls for Simple and RGB lamps, including custom colors, with clearer feedback for brightness, mode and effect settings.
- Improved BLE recovery after firmware changes, with a repair action that never removes pairings automatically.
- Optional fullscreen mode, a more compact connection control and clearer control panels.
- The stable app checks GitHub for newer stable releases at launch. Downloads and installation remain manual.

Use a recent official `develop` firmware for reliable fragmented UART commands and live mode, brightness and ramp feedback. Power and RGB color still do not have live readback.

This APK updates the stable app in place when signed with the existing release key. Lamp-Da Beta remains a separate installation.
