# Lamp-Da Android 0.4.1

- Sync the lamp's output state, mode, brightness and effect parameter on connection.
- Restore an active sunrise or sunset countdown on reconnect.
- Stop the displayed lamp's timer from the controls, with firmware confirmation.
- Update UART shortcuts for the new debug category, button bindings, battery flashes, indicator and microphone settings.

These features target official firmware `develop` at `7bb2044`. The app does not
receive live power changes or the current RGB color.
